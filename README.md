One haiku about debugging, in the classic 5-7-5 shape. A cursor blinks at
three in the morning, the last log line insists everything worked, and the
final line turns the whole thing around: nothing was fixed, the bug simply
moved somewhere else. Quiet, a little bleak, and true to any long night
spent staring at a stack trace.

## Run it

```sh
python3 main.py
```

The program checks the haiku first — three lines, 5-7-5 syllables, at most
200 characters — then writes it to `/output/entry.txt`. Python 3 standard
library only, no dependencies, and the output is identical on every run.
